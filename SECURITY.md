# Security Policy

## Supported Versions

This project is in active development. Security fixes are applied to the latest `main` branch.

## Reporting a Vulnerability

Please do **not** open public issues for security vulnerabilities.

Instead, report privately with:

- a clear description of the issue
- reproduction steps or proof-of-concept
- expected impact and affected components
- any mitigations already identified

We will acknowledge receipt, triage severity, and provide remediation guidance/status updates.
